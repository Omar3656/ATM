ATM

CONTEXT:

Automatic Teller Machines (ATMs) are essential components of modern financial infrastructure, used daily for transactions such as balance inquiries, cash withdrawals, and deposits. Despite their widespread use, the workings behind these machines are not often wondered by people.

The objective of this project is to develop a functional ATM simulation system that models both user-facing operations and core back-end mechanics. Key features include user authentication, transaction logging (history), real-time cash inventory tracking, and an optimal bank-note dispensation algorithm (handling $50, $100, $200, and $500 denominations based on available physical stock).

ALGORITHM:

Possible Inputs:
User Account Number / Card ID and PIN (NIP).
Selected option from the main menu
Amount of cash to withdraw or deposit
New PIN for PIN change operations.

Process:
All the corresponding inputs are going to be asked once the user already chose an option and the processes to be done could be:
Main Navigation Menu
Authentication & Security Gate
Core Business Logic
Termination

Possible Outputs:
Account Information
Dispensation Output
Transaction Receipt / History
